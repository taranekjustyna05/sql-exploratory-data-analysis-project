# SQL Exploratory Data Analysis Project
---
## 📖 **Overview**
This repository contains a collection of SQL scripts demonstrating vaious analytical techniques, such as changes over time, cumulative, performance, data segmentation, part-to-whole analysis.

## 📚 **About the Project** 
---
This project was created as part of a SQL course by **Data with Baraa** and was used as a hands-on exercise to develop my skills in SQL, data querying, data cleaning, joins, aggregations, and analytical problem-solving.
